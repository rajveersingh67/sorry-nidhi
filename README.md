# 💖 Romantic Apology Website for Meri Jaan

A complete, responsive, romantic apology website built with React, Vite, Tailwind CSS, Framer Motion, and Lucide Icons.

---

## 🌟 Features Included

1. **First Screen — A Special Apology**
   - Fullscreen dreamy romantic opening with soft blush and lavender gradient lighting.
   - Animated greeting: *"Hey, My Favourite Person... 🥺❤️"*, *"I Know You're Angry With Me..."*, and heartfelt intro text.
   - Sad crying emoji avatar with glowing aura.
   - Glowing **"Open My Heart 💌"** button that unseals the letter, triggers heart confetti, and starts soothing background music.

2. **Your 3 Uploaded Apology Photos**
   - Displays all three uploaded images with intact aspect ratios (no stretching or distortion) in glassmorphism cards:
     - `crying-emoji.jpg`: *"Me right now, asking for your forgiveness 🥺"*
     - `bowing-man.jpg`: *"My ego doesn't matter more than your feelings."*
     - `kneeling-character.jpg`: *"I'm genuinely sorry, meri jaan. ❤️"*

3. **Long Handwritten Apology Letter**
   - Vintage textured paper styling (`paper-card`) with wax seal and decorative ribbon.
   - Complete verbatim heartfelt text in natural Hinglish/English.
   - Realistic typewriter animation with smooth cursor, **"Read All Instantly"** toggle, and **"Read My Letter Again 💌"** replay button.

4. **Cinematic Video & Memory Reveal Section**
   - Title: *"A Little Something Just For You 🎬"*
   - Rounded video player with copyright-safe ambient stream, play/pause controls, falling rose petals, and graceful offline visualizer fallback.
   - 3 interactive reveal/flip cards:
     - *Things I Love About You ❤️*
     - *Memories I Treasure 🥹* (with editable photo placeholder slots)
     - *A Promise From My Heart 💗*

5. **5 Little Reasons You Mean So Much To Me 💖**
   - 5 animated cards appearing sequentially.
   - Hover float physics and interactive heart explosions on click.

6. **The Scrapbook Promise Wall**
   - Title: *"Things I Want To Do Better, Meri Jaan 🫶"*
   - Realistic pushpins and washi tape styling with natural tilt angles.
   - 5 sincere, grounded promises with interactive "Hold me to this" seal toggle.

7. **Interactive Apology Game**
   - Title: *"Can Your Silly Boy Have One Little Moment? 🥺"*
   - Two pressure-free choices:
     - *"Okay, Tell Me ❤️"* (burst of hearts + warm gratitude message)
     - *"I'm Still Angry 😤"* (gentle, validating reassurance with virtual embrace)
   - Allows switching responses anytime without guilt-tripping.

8. **The Final Surprise & Virtual Hug**
   - Deep pink-to-purple cinematic gradient with glowing stars and ambient orbs.
   - Sincere closing message.
   - Glowing **"Send You A Big Hug 🫂"** button triggering multi-burst heart confetti and warm delivery toast.
   - Optional message box for her thoughts with a one-click **"Copy My Message 📋"** button and WhatsApp share option.

9. **Extra Details**
   - Built-in Web Audio API romantic piano engine (100% self-contained, works offline, no external audio file dependencies).
   - Animated floating music controller with volume toggle.
   - Custom desktop glowing heart cursor (preserves normal touch behavior on mobile).
   - Smooth scroll progress bar at top.
   - Responsive mobile navigation menu.
   - Floating back-to-top button.
   - Opening beating heart loading screen.

---

## 🚀 How to Run & Preview

The development server is already running! You can open it right away in your browser:

- **Local Preview:** [http://localhost:5173/](http://localhost:5173/)
- **Mobile Preview (Same Wi-Fi network):** `http://<your-local-ip>:5173/`

### Commands
- Start dev server: `npm run dev`
- Build for production: `npm run build`
- Preview production build: `npm run preview`
